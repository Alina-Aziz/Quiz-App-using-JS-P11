# Quiz-App-using-JS-P11
💡A clean, interactive JavaScript quiz app testing core concepts like closures, async/await, and DOM manipulation—built with JS to showcase fundamental web development skills. 

📈 Test your JavaScript knowledge with this interactive quiz app covering fundamental concepts.

## 🌟Features
- 10 challenging JavaScript questions
- Instant answer feedback
- Score tracking
- Mobile-responsive design

##🛠 Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript
  
  
- ⚪ No frameworks or libraries used
- ⚪ Modern DOM Manipulation: Uses dataset attributes and classList
- ⚪ Event Delegation: Efficient event handling
- ⚪ Clean State Management: Proper reset between questions

## UI/UX Elements
- Clean, accessible interface
- Visual feedback (green/red coloring for answers)
- Progress indication (question numbering)
- Play again functionality
